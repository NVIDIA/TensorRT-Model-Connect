# Security

NVIDIA takes security concerns seriously. Do not report potential security
vulnerabilities through a public GitHub issue, discussion, or pull request.

To report a potential vulnerability in TensorRT-Model-Connect or another NVIDIA
product, use the
[NVIDIA vulnerability-reporting page](https://www.nvidia.com/en-us/security/report-vulnerability/)
or email [NVIDIA PSIRT](mailto:psirt@nvidia.com).

If reporting a potential vulnerability by email, encrypt the report using
[NVIDIA's public PGP key](https://www.nvidia.com/en-us/security/pgp-key/) and
include:

1. The product name and affected version or branch.
2. The vulnerability type, such as code execution, denial of service, or buffer
   overflow.
3. Instructions to reproduce the vulnerability.
4. Proof-of-concept or exploit code, when available.
5. The potential impact and how an attacker could exploit the vulnerability.

For non-security bugs, feature requests, and documentation issues, use this
repository's GitHub issue tracker.
