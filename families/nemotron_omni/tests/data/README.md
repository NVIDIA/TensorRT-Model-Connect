# Omni validation fixtures

`reference.json` records six exact independent vLLM 0.20.0 outputs, pinned
checkpoint and input revisions, decoding parameters, and original lossless frames.
It is an immutable oracle, not output generated by the Model Connect adapter.
The owning E2E test retains the normalized edit-distance limit of 0.15.

The image is a byte-for-byte owning copy of the pinned public
`nvidia/Cosmos3-Edge` checkpoint asset. Its original repository, revision,
and filename remain in `reference.json`. All replay inputs are local
so offline CI does not depend on another checkpoint being cached.
The four video PNGs are lossless copies of the original real decoded frames,
with source checkpoint revision, frame indices and timestamps
in `reference.json`. They retain the exact executed independent reference input
(about 1.5 MiB total), avoiding OpenCV/FFmpeg version-dependent color rounding. They are generic validation inputs, not imports of another
Model Connect family. Four actual video frames retain their original timestamps;
the versioned lossless files are the exact pixels used for the independent reference.

`speech_16k_mono.wav` is an owning copy of the existing Model Connect speech
fixture at commit `c348158806710ed93eda5e07edb8b1b4b77692a2`. It is a 16 kHz mono
recording saying “Hello there, how is the weather today?”. No sibling family
is read or imported at test execution time.

The audio/video fixture combines independent clips with explicit zero origins.
It checks both modalities, not physical synchronization or arbitrary offsets.
