No immutable documentation release has been published. The current website
tracks `main` and the package version remains a development contract.

Nightly tags and CI artifacts are validation records, not user releases. Do not
infer a compatibility promise or model-support matrix from their existence.

When a user release is published, record its tag and date, supported dependency
cohort, user-visible API and bundle contract, exact model qualification changes,
known limitations, and any explicit compatibility promise here.
